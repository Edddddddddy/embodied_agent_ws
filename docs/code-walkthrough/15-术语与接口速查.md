# 15 术语与接口速查

## 1. 节点速查

| 节点 | 类型 | 核心职责 |
|---|---|---|
| `audio_frontend` | 普通 C++ Node | PortAudio、AEC、VAD、播放 |
| `online_agent` | 普通 Python Node | 云 ASR/LLM/TTS 编排 |
| `offline_agent` | 普通 Python Node | 本地 ASR/LLM/TTS 编排 |
| `action_guard` | C++ LifecycleNode | 不可信 JSON 到可信命令 |
| `typed_action_bridge` | C++ Node | typed Topic 到 Action goal |
| `simulation_control` | C++ LifecycleNode/component | Action、BT、executor、cmd_vel |
| `hardware_controller` | C++ Node | 协议、UART/SPI、watchdog |
| `nav2_client` | C++ Node | NavigateToPose client |

## 2. Topic 速查

| Topic | 类型 | Producer -> Consumer | QoS/语义 |
|---|---|---|---|
| `/audio/clean_pcm` | `UInt8MultiArray` | AudioFrontend -> Agent ASR | best effort，16 kHz mono int16 |
| `/audio/silence_timeout` | `Empty` | AudioFrontend -> Agent | 一句话 commit |
| `/audio/tts_pcm` | `UInt8MultiArray` | Agent -> AudioFrontend | best effort，TTS sample rate |
| `/agent/text_input` | `String` | CLI/test -> Agent | 绕过 ASR 的文本入口 |
| `/agent/asr_partial` | `String` | Agent -> observer | 中间识别文本 |
| `/agent/asr_final` | `String` | Agent -> observer | 最终识别文本 |
| `/agent/action_candidate` | `String JSON` | Agent -> Guard | 不可信动作 |
| `/robot/action_rejected` | `String` | Guard -> observer | 静态拒绝原因 |
| `/robot/action_command` | `String JSON` | Guard -> legacy/hardware | 已规范化可信 JSON |
| `/robot/action_command_typed` | `RobotCommand` | Guard -> bridge | 强类型可信命令 |
| `/robot/action_feedback` | `String JSON` | bridge -> observer | Action feedback 镜像 |
| `/robot/action_result` | `String JSON` | bridge -> observer | Action result 镜像 |
| `/robot/bt_status` | `String JSON` | SimulationControl -> observer | BT 阶段/终态变化 |
| `/robot/action_ack` | `String JSON` | executor/hardware -> observer | 接收/发送证据，非统一完成证据 |
| `/robot/emergency_stop` | `Empty` | safety/operator -> executor | 当前为软件停车事件；未接通 Action 终止和 latched reset |
| `/scan` | `LaserScan` | Gazebo/LiDAR -> controller/Nav2 | SensorDataQoS |
| `/cmd_vel` | `Twist` | controller -> base/bridge | 底盘速度 |
| `/odom` | `Odometry` | base/Gazebo -> observer/Nav2 | 里程计 |
| `/diagnostics` | `DiagnosticArray` | controller -> monitoring | 1 Hz 快照 |

绝对名称以 `/` 开头，不自动跟随 namespace；相对名称会在节点 namespace 下展开。

## 3. Action 速查

### ExecuteRobotCommand

```text
Goal: RobotCommand
Feedback: phase, progress, detail
Result: success, status, message
```

Result status：UNKNOWN、SUCCEEDED、REJECTED、CANCELED、TIMED_OUT、BLOCKED。

### NavigateToPose

```text
Goal: PoseStamped target pose
Feedback: current pose, navigation time, distance remaining, recoveries...
Result: ROS action result code + Nav2 error fields（依版本）
```

## 4. RobotCommand 动作

| action_type | 有效字段 | 当前仿真 | 当前硬件协议 |
|---|---|---|---|
| STOP | 无 | 支持 | 支持 |
| MOVE | linear_x, duration_s | 支持 | 支持 |
| TURN | angular_z, duration_s | 支持 | 支持 |
| WAVE | count | BT/仿真不支持 | 支持编码 |
| SET_LED | color | BT/仿真不支持 | 支持编码 |
| SET_MODE | mode | 支持 | 协议不支持 |

## 5. 关键参数

| 参数 | 默认 | 意义 |
|---|---:|---|
| `frame_ms` | 20 ms | 麦克风帧长 |
| `vad_rms_threshold` | 0.018 | 能量 VAD 阈值 |
| `silence_timeout_s` | 0.4 s | 句尾静音 |
| `aec_taps` | 64 | NLMS FIR taps |
| `aec_step` | 0.35 | NLMS 更新步长 |
| `aec_delay_ms` | 80 ms | reference 粗延迟 |
| `control_rate_hz` | 20 Hz | 控制 tick |
| `max_linear_speed` | 0.22 m/s | 控制后端线速限制 |
| `max_angular_speed` | 1.0 rad/s | 控制后端角速限制 |
| `emergency_distance` | 0.22 m | 统一前进急停 |
| `obstacle_distance` | 0.50 m | 自主模式转向阈值 |
| `scan_timeout` | 0.50 s | 传感器过期 |
| `action_timeout_s` | 12 s | Action 硬上限 |

Guard 的最大范围比控制器后端更宽：move 可 clamp 到 0.5 m/s，Gazebo controller 再 clamp 到 0.22 m/s。最终执行限制取各层更严格值。

## 6. 状态速查

### Agent

```text
listening -> retry_listening
listening -> thinking -> speaking -> listening
                     \-> error -> listening
```

### Lifecycle

```text
unconfigured -> inactive -> active
active -> inactive -> unconfigured
any -> finalized(shutdown)
```

### ActionExecution

```text
RUNNING -> SUCCEEDED | CANCELED | BLOCKED | TIMED_OUT
```

### BT stage

```text
validate -> safety -> execute -> confirm
```

## 7. 术语表

| 术语 | 含义 |
|---|---|
| AEC | Acoustic Echo Cancellation，用播放参考抵消回声 |
| NLMS | Normalized Least Mean Squares，自适应滤波算法 |
| VAD | Voice Activity Detection，判断音频帧是否含语音活动 |
| KWS | Keyword Spotting，音频级关键词/唤醒词检测 |
| ASR | Automatic Speech Recognition，语音转文本 |
| TTS | Text To Speech，文本转语音 |
| PCM16 | 16-bit 脉冲编码音频样本 |
| QoS | DDS 传输和历史策略 |
| RMW | ROS 2 middleware abstraction |
| DDS | ROS 2 默认使用的分布式数据通信标准族 |
| Executor | 调度 ROS callback 的运行器 |
| Callback Group | 限定 callback 是否允许并行的分组 |
| LifecycleNode | 有 configure/activate 等受控状态的节点 |
| Action | goal/feedback/result/cancel 长任务协议 |
| BT | Behavior Tree，组合式行为编排 |
| Blackboard | BT 节点共享的当前 goal 上下文 |
| pluginlib | ROS 2 运行时 C++ 插件加载机制 |
| PImpl | 将实现类型隐藏在私有 Impl 中的 C++ 技法 |
| Watchdog | 超时后主动采取安全动作的监控器 |
| CRC | 检测传输位错误的循环冗余校验 |
| TF | ROS 坐标系随时间的变换树 |
| Costmap | 将地图与传感器转换成导航代价网格 |
| NavFn | Nav2 网格全局规划插件 |
| DWB | Nav2 动态窗口局部控制器 |
| SLAM | 同时定位与建图 |
| odom | 连续但可能漂移的局部里程计坐标 |
