# 多模态演示开发记录

本目录记录“建图、导航、语音控制、键盘控制”统一演示的开发过程。它不是用户操作手册，而是面向开发、评审和面试复盘的工程档案。

- `PLAN.md`：目标、迭代边界、验收门槛与分支安排。
- `DECISIONS.md`：关键架构选择及其理由。
- `REFERENCES_AND_TOOLS.md`：使用的上游资料、命令和工具。
- `PITFALLS.md`：已发现的风险、失败现象与解决办法。
- `ENGINEERING_LOG.md`：按日期追加的实际开发、测试和证据。

维护规则：

1. 代码变化与对应记录放在同一个功能 PR。
2. 只记录已经观察到的事实；规划项明确标记为“计划中”。
3. 快速现场演示与严格发布验收使用不同 evidence kind，不互相冒充。
4. 关键业务代码使用中文注释解释设计原因和风险边界，不做逐行翻译。
