# GTSAM 非局部边一致性门控消融证据

- 数据：OpenLORIS `corridor1-1`。
- 固定位姿图 SHA256：`792ecb7d1871b506274423631fdf16da60b52e46aa18eaa1287cddbd4cadbc65`。
- 图规模：1834 个连续节点、2751 条输入约束、0 条悬空边；每组匹配 1828 个真值位姿。
- 门控：只作用于 node ID 间隔至少 20 的非局部边；平移残差上限 2 m，偏航残差上限 π/4。
- 在线决策不使用真值；真值只在实验结束后计算 ATE/RPE。

门控比较候选约束与“优化前当前位姿图”预测的相对位姿，只硬拒绝明显不一致的非局部边；中等残差
仍交给 Cauchy 鲁棒核连续降权。本序列中门控拒绝 23 条边，ATE 比单独 Cauchy 再下降 4.28%。

边界：ID 间隔只是非局部边启发式，不是 Karto 原生 closure 标签；严重累计漂移也可能使真实回环
与当前图预测不一致，因此门控默认关闭，不能仅凭本序列自动推广到其他场景。该结果不能表述为
“前端回环 precision 提升”，正式前端质量仍由 closure callback 和独立真值相对位姿残差衡量。
